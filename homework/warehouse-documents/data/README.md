# Заказ 02 — сортировка документов склада
В `incoming/` лежат 260+ поступивших документов. Внутри корректного `.json` ожидаются
`document_id`, `order_id`, `document_type`, `date`, `customer`, `amount`.

Реализуйте обработку: `sorted/YYYY-MM/<тип>/`, отдельный `quarantine/` для плохих
документов и журнал `processing_log.csv`. Не теряйте исходники и не перезаписывайте
разные документы с одинаковым именем. Повторный запуск не должен плодить копии.

В данных есть одинаковые имена из разных папок, пустые файлы, JSON с ошибкой,
документы с одинаковым ID, пропущенные поля и кириллические пути.

Проверки: повторный запуск без изменения входа; две папки с `акт_001.json`;
невалидный JSON; внезапное прерывание обработки (запустите на копии).
Сдача: скрипт, журнал обработки, количество успешных/проблемных документов.
