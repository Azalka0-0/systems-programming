#02-Обработчик документов склада

Python-программа для автоматической обработки складских документов в формате JSON.

## Возможности

- Поиск документов во вложенных папках.
- Проверка обязательных полей JSON.
- Обнаружение повторяющихся document_id.
- Сортировка корректных документов по месяцу и типу.
- Перемещение копий проблемных документов в карантин.
- Создание CSV-журнала обработки.
- Защита от повторного копирования.
- Защита от перезаписи документов с одинаковыми именами.
- Сохранение исходных документов без изменений.

## Структура проекта

- `src/main.py` — основная программа.
- `data/incoming/` — исходные документы.
- `output/sorted/` — корректные документы.
- `output/quarantine/` — проблемные документы.
- `output/processing_log.csv` — журнал обработки.
- `tests/` — папка для тестов.
